# 🏥 Hospital Wait Time Analysis Dashboard

An interactive **Power BI Dashboard** developed to analyze hospital wait times, patient flow, and operational performance across different departments and hospitals. The dashboard provides insights into average wait times, triage levels, and department-wise performance through interactive visualizations.

# 📖 About

The **Hospital Wait Time Analysis Dashboard** helps healthcare administrators monitor patient waiting times and evaluate operational efficiency across hospitals and departments.

The dashboard enables users to compare hospitals, identify departments with longer wait times, and analyze patient priority levels using interactive Power BI visuals.
